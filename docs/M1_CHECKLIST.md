## M1 implementation decisions (recorded in the Decision Log)

1. `parse_certificate_chain` is `async` — the M0 stub was synchronous, but
   `pyhanko-certvalidator`'s path validator (`async_validate_path`) is
   async-only.
2. `asn1crypto` promoted to an explicit dependency (was only transitive via
   `pyhanko-certvalidator`) — `app.parsing` imports it directly.
3. `hostname_mismatch: bool | None` added to `Certificate` — the M0 data
   model stub described category 5 as "its own boolean/flag" but the field
   itself wasn't added until M1.
4. `mypy` overrides `asn1crypto.*` with `ignore_missing_imports` — the
   library ships no type stubs or `py.typed` marker.
